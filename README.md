# Paradise Nursery Shopping Application

## Project Overview

Paradise Nursery is a React-based online shopping application for houseplants. Users can browse different categories of plants, add plants to a shopping cart, manage quantities, and view the total cost of their selected plants.

## Features

* Browse houseplants by category
* View plant names, images, and prices
* Add plants to the shopping cart
* Increase or decrease plant quantities
* Remove plants from the cart
* View the total cart amount
* Continue shopping from the cart
* Checkout option with a "Coming Soon" message
* Dynamic shopping cart item count

## Technologies Used

* React.js
* Redux Toolkit
* JavaScript
* HTML
* CSS
